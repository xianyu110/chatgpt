🪪 自分の公式アカウントが欲しい

OpenAI 互換の Key 一つで、複数のモデルにつながります。入り口：tryallapi.com。

経路一

momoAI 旧ウェブノード（性能を落とさない Plus ノード）

「ノードカードの壁」型の旧ホールです。トップバーで、性能を落とさない Plus ノード、SuperGrok、Gemini、Claude Pro Max、国内向け Codex サイトなどの入り口を切り替えられます。

空きノードは緑のバーで「おすすめ」、混雑ノードは黄色のバーで「利用可」と出ることが多いです。一つが遅くなったら、別のカードに切り替えれば十分です。ウェブミラーはすぐに会話を始めるのに向きますが、公式アカウントを丸ごと持つのと同じではありません。

入り口：https://old.trygpt.asia/list/

旧ドメインの転送：https://maynorai.top/ → 同上

旧ホールを開く
経路二

momoAI.New 上級ノードホール

いまより多く使われている新しいホールで、ブランド名は momoAI.New です。左サイドバーは製品別：GPT Plus 上級ノード、Gemini Pro、SuperGrok、AI 画像生成、Claude Pro Max、代行チャージサイト、国内向け Codex サイトなど。

ノードはカードで表示され、「すべて / おすすめ / 混雑」で絞り込め、リアルタイムの負荷も見られます。緑のバーで数値が小さいものを優先してください。黄色の「利用可」は入れるものの、混んでいる可能性があります。サブスクリプション種別が合わないと出たら、先にサイト内ストアで購入するか、カードコードで交換してください。

入り口：https://trygpt.asia/list/#/home

経路三

ChatGPT Plus / GPT Pro 公式代行チャージ

すでに（またはこれから用意できる）自分の ChatGPT アカウントがあり、海外のクレジットカードで払えないだけなら：自分の公式アカウントに Plus / Pro をチャージし、その後も公式サイトで使います。

サイトは「24時間全自動 · 正規 iOS チャネル」を名乗り、WeChat と Alipay に対応し、通常 1〜2 分で反映すると書いています。宣伝数字（1.3 万件以上に対応、凍結率 <0.1%、通常 1〜3 分で反映）はサイト自身の主張であり、このページは転記するだけで、独自には検証していません。この経路では、サイトの手順に従ってアカウント関連の証憑を出す必要があり、それ自体にリスクがあります。

  1. 次の 2 つのドメインに入ったことを確認し、出所の分からない模倣サイトには近づかないでください。
  2. 自分のアカウントにだけチャージし、出所不明の「完成アカウント」は買わないでください。
  3. チャージ中はページを閉じず、注文とカスタマーサポートの記録を残してください。
  4. サイトの約束（日割り返金、凍結保証など）は当日のページ規則に従います。注文前によく読んでください。

入り口：https://chongzhi.chatgpt-plus.top/

同一サイトの予備：https://chongzhi.trygpt.asia/

💳 代行チャージサイトを開く

⚠️ 少し話すだけなら、ウェブノードの方が簡単です。アカウントを自分のものにし、機能を公式サイトに合わせたいときに、この経路を選んでください。

経路四

国内向け Codex サイト（momoAPICodex）

Codex Desktop / CLI でコードを書いたり Agent を動かしたり、あわせて GPTimage2 で画像を出したい人向けです。これは OpenAI 公式のサブスクリプションではなく、中国国内から届く第三者の中継です。

momoai.asia で登録し、従量または月額を開き、対応グループの API Key を作り、CC Switch で公式クライアントを中継アドレスに向けます。2026年11月18日更新：GPT-6.2 Astra が利用可能で、モデル ID は gpt-6.2-astra です。日常的な作業では、コンソールの一覧から gpt-6.2-sol を選ぶこともできます。料金と一日あたりの枠は変わるので、コンソールのその時点の規則に従ってください。

  1. Base URL には中継のルート、例えば https://momoai.asia を入れ、https://api.openai.com は指さないでください。
  2. Key は Codex に対応したグループ（多くは月額の Codex グループ）のものである必要があります。グループを間違えると「モデル非対応」や枠なしになります。
  3. モデル ID は当日のコンソール一覧に従い、すでに下された名前を記憶だけで書かないでください。
  4. 以前に公式の Codex アカウントでログインしていた場合は、先にログアウトしてから API Key に切り替えてください。

サービス入り口：https://momoai.asia/

予備ドメイン：https://codex.trygpt.asia/

経路五

momoAPIPro / TryAllAPI インターフェース集約

自分のプロジェクト、スクリプト、デスクトップクライアントからモデルを呼びたいなら、この経路の方が向いています。OpenAI 互換の Base URL 一つで、複数のモデルにつながります。ChatGPT のウェブチャットルームではありません。

トップのブランド名は momoAPIPro です。「開発者 10,000 人以上、18 か月の安定運用」と宣伝していますが、具体的なモデル一覧、単価、グループはコンソールに従ってください。momoai.asia も API を出しています。momoai は Codex、月額、クライアント中継に近く、TryAllAPI は多モデルの従量接続を強調します。

import OpenAI from 'openai';

const client = new OpenAI({
  apiKey: 'your-api-key',
  baseURL: 'https://tryallapi.com/v1'
});

const completion = await client.chat.completions.create({
  model: 'gpt-4o',
  messages: [{ role: 'user', content: '创造无限可能...' }]
});

入り口：https://tryallapi.com/

🔑 まずグループとモデル ID を確認

Codex や API が 401、枠なし、モデル非対応を返すとき、多くは Key のグループかモデル名がコンソールと一致していないだけで、「サイト全体が落ちた」わけではありません。

📌 料金は当日の表示だけを基準に

キーやログイン状態をチャットや公開リポジトリに貼らないでください。代行チャージでは、とくにドメインを確認してください。古い記事やスクリーンショットの月額や付与枠は、もう古い可能性があります。所在地の法令とプラットフォームの規約も守ってください。

❓ よくある質問

開いてすぐに話したいだけです。どれを選べばいいですか？

まず旧版ノードホール https://old.trygpt.asia/list/ をブックマークしてください。新しいサイト https://trygpt.asia/list/#/home も開けます。

公式の全機能と、自分のアカウントが欲しい場合は？

公式代行チャージを使います：https://chongzhi.chatgpt-plus.top/ 、予備は https://chongzhi.trygpt.asia/ 。自分のアカウントにだけチャージし、ドメインを確認し、注文記録を残してください。

コードを書いたり、Codex を使うならどこへ行けばいいですか？

https://momoai.asia/ で Key を発行し、CC Switch でクライアントを中継アドレスに向けてください。451 を返す codexinstall.asia は使わないでください。

あるドメインが開かないときは？

まず本文に挙げた予備アドレスを試し、その時点のサイト表示に従ってください。出所の分からない「最新ミラー」をまた探すより、確認済みで開けた入り口をブックマークしておく方が大切です。
