Channel 3

Official ChatGPT Plus / GPT Pro top-up

If you already have (or can set up) your own ChatGPT account and just cannot pay with an overseas credit card: top up Plus / Pro on your own official account, then keep using the official site.

The site describes itself as a “24/7 fully automatic, formal iOS channel,” accepts WeChat Pay and Alipay, and says credit usually arrives in 1–2 minutes. Promotional figures (13,000+ customers served, ban rate <0.1%, typical arrival in 1–3 minutes) are the site’s own claims; this page only restates them and has not independently audited them. The trade-off is that you must follow the site’s process and provide account-related credentials, which carries its own risk.

  1. Confirm you are on one of the two domains below, and stay away from look-alike sites of unknown origin.
  2. Only top up your own account. Do not buy “ready-made accounts” from unknown sources.
  3. Do not close the page during top-up, and keep your order and support records.
  4. Site promises (same-day refunds, ban warranties, and so on) follow the rules on that page—read them before you order.

Channel 4

Domestic Codex site (momoAPICodex)

For people who want to write code or run agents with Codex Desktop / CLI, or also generate images with GPTimage2. This is not an official OpenAI subscription, but a third-party relay that can be reached from mainland China.

Register at momoai.asia, start a usage-based or monthly plan, create an API key in the matching group, then point the official client at the relay address with CC Switch. Updated 18 November 2026: GPT-6.2 Astra is now available; the model ID is gpt-6.2-astra. For everyday tasks you can also choose gpt-6.2-sol from the live console list. Plan prices and daily quotas change—follow the live console rules.

  1. Set the Base URL to the relay root, for example https://momoai.asia, not https://api.openai.com.
  2. The key must come from a group that supports Codex (often a monthly Codex group). The wrong group leads to “model not supported” or no quota.
  3. Use model IDs from the console list on the day; do not type names from memory that may already have been retired.
  4. If you previously signed in with an official Codex account, sign out first, then switch to the API key.

Channel 5

momoAPIPro / TryAllAPI aggregator

If you want to call models from your own project, script, or desktop client, this path is a better fit. One OpenAI-compatible Base URL, many models. It is not a ChatGPT web chat room.

The homepage is branded momoAPIPro. It promotes “10,000+ developers and 18 months of stable operation”; the actual model list, unit prices, and groups follow the console. Both this site and momoai.asia offer APIs: momoai is closer to Codex, monthly plans, and client relays; TryAllAPI emphasizes multi-model, usage-based access.

import OpenAI from 'openai';

const client = new OpenAI({
  apiKey: 'your-api-key',
  baseURL: 'https://tryallapi.com/v1'
});

const completion = await client.chat.completions.create({
  model: 'gpt-4o',
  messages: [{ role: 'user', content: '创造无限可能...' }]
});

💡 Please read this before you start

🔑 Check the group and model ID first

If Codex or the API returns 401, has no quota, or says a model is not supported, it is usually a mismatch between the key’s group or the model name and the console—not that “the whole site is down.”

📌 Prices are only valid on the day

Do not paste keys or login state into chat or a public repository. For official top-up, double-check the domain. Monthly fees and bonus quotas in old posts or screenshots may be outdated. Please also follow local laws and the platform’s terms.
